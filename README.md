# TTKFARMPRO

Dashboard responsivo para gerenciamento de dispositivos, contas, calendário de conteúdo, desempenho e receita atribuída.

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Estado atual

Primeira versão do frontend com dados demonstrativos, filtros de período, busca, exportação CSV, navegação e visual adaptado para desktop, tablet e celular. A integração com dispositivos, autenticação e fontes reais de métricas será adicionada na camada de backend.
